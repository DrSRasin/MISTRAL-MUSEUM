# Contributing exhibits

## What belongs here

- Failures that are **funny and true**  
- Primary quotes (FAQ text, logs, screenshots described in prose)  
- Classification + 2026 translation so future readers are not misled  

## What does not

- Live secrets, patient data, credentials  
- Unverified “someone said” without operator attestation  
- Pure mockery without a specimen  

## How to add

1. New file under `exhibits/` or new section in an existing wing.  
2. Follow the plaque template (see any exhibit).  
3. Update wing table in `README.md`.  
4. Commit with a complete sentence message.  
5. Push only with operator GO if remote publish is intentional.
